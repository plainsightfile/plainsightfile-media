# Do-it-yourself videos

Put a script here as a `.txt` file (the layout is in the "Rhea Lity Check: Doing It Yourself" doc, Step 2) and commit it.
GitHub builds the video automatically: open the **Actions** tab, click the newest **make-video** run, and download
the file under **Artifacts** (a zip with `video.mp4`, `cover.jpg`, `caption.txt`, `pinned-comment.txt` and the slide images).

`example-ballot.txt` is a real, checked script you can copy.
